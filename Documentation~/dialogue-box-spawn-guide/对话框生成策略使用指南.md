# 对话框生成策略使用指南（工具侧 API 参考）

> 本文档是"生成策略接缝"（`IDialogueBoxSpawnStrategy`）的**开发者接口手册**，面向需要自定义对话框"出现在哪 / 何时出现 / 是否出现 / 是否保留"的策划、美术与程序。

> 所有类型均位于命名空间 `MicrobialNet.Story.UI`（程序集 `com.microbialnet.story.UI`，Runtime）。

> 设计原则：**策略只做决策，不做关闭**；框架在正确时机回调策略并应用结果，剧情代码 / 池化 / 层级 / 生命周期均不受影响。无策略（null）时行为完全等价于此前静态定位。

> 本说明文档随工具包（`com.microbialnet.story`）一并外放。

---

# 类与接口

## 核心接缝：`IDialogueBoxSpawnStrategy`

```csharp
namespace MicrobialNet.Story.UI
{
    public interface IDialogueBoxSpawnStrategy
    {
        /// 解析本次弹出的决策。context 提供样式 / 业务数据 / 活动框；返回的决策用于覆盖 spec 静态字段。
        /// 实现应保持对 context 只读；需要序列 / 历史信息时，请在实现内部用字段自管理
        /// （如 invocation 计数、已用点集合、分组哈希），因为 context 每次都是新构建的。
        /// 不应返回 null（返回 null 时管理器按"无策略"处理）。
        DialogueBoxSpawnResolution Resolve(DialogueBoxSpawnContext context);
    }
}
```

---

## 决策上下文：`DialogueBoxSpawnContext`（只读，管理器构建）

| 字段 | 类型 | 说明 |
|---|---|---|
| `styleKey` | `string` | 本次弹出的样式键（如 `story-line`）。 |
| `spec` | `DialogueBoxSpec` | 原始请求（含静态 `position` 兜底、`layer`、`tag` 等）。策略可读取，**不应长期持有**。 |
| `payload` | `object` | 业务数据载荷（如 `StoryFlow.Line`），按剧情上下文决策。 |
| `activeBoxes` | `IReadOnlyList<DialogueBox>` | 当前活动（含开/关中）的对话框，**已按层级 + 弹出顺序排好**。每个元素的 `spec.position` 即其已解析的最终定位——用于避让、级联偏移、去重。 |
| `totalActive` | `int` | 活动框总数（= `activeBoxes.Count`，冗余便于使用）。 |

---

## 决策结果：`DialogueBoxSpawnResolution`（覆盖 spec）

| 字段 | 类型 | 说明 |
|---|---|---|
| `position` | `DialogueBoxPosition` | 最终定位（**必填**）。传 `null` = 沿用 `spec.position` 静态值。 |
| `delay` | `float` | 打开延迟（秒）。`0` = 立即。用于错峰 / 排队 / 节拍。 |
| `cancel` | `bool` | `true` = **取消本次弹出**（如去重 / 条件不满足）；管理器直接返回 `null` 句柄、不显示。 |
| `layerOverride` | `int?` | 层级覆盖（非 null 时覆盖 `spec.layer`，影响堆叠顺序与模态输入拦截）。 |
| `persistent` | `bool?` | 点击「继续」是否保留自身（非 null 时覆盖 `spec.persistent`）。`true` = 点了只推进剧情、不关闭自己（级联串保留显示用）。 |

---

## 资产基类：`DialogueBoxSpawnStrategyAsset`

`ScriptableObject` 基类，供在 Inspector 创建并拖拽配置；纯代码策略亦可直接实现 `IDialogueBoxSpawnStrategy`。自定义业务策略继承本类并覆写 `Resolve` 即可，**无需改动管理器或剧情代码**。

```csharp
public abstract class DialogueBoxSpawnStrategyAsset : ScriptableObject, IDialogueBoxSpawnStrategy
{
    public abstract DialogueBoxSpawnResolution Resolve(DialogueBoxSpawnContext context);
}
```

## 管理器接线：`DialogueBoxManager`（关键方法）

| 成员 | 签名 | 说明 |
|---|---|---|
| `Instance` | `static DialogueBoxManager` | 懒加载单例。 |
| `Ensure()` | `static DialogueBoxManager Ensure()` | 确保存在实例（场景里没有时自动创建）。 |
| `RegisterSpawnStrategy` | `void RegisterSpawnStrategy(string styleKey, IDialogueBoxSpawnStrategy strategy)` | 为某样式注册**默认**策略（优先级低于 `spec.spawnStrategy` 逐次覆盖）。 |
| `Show` | `DialogueBoxHandle Show(DialogueBoxSpec spec)` | 弹出；内部在落地前构建 context 调策略、用结果覆盖 spec；`cancel=true` 时返回 `null`。 |
| `CloseTop` | `void CloseTop()` | 关闭最顶层对话框。 |
| `CloseAll` | `void CloseAll(bool immediate = true)` | 关闭全部；`immediate=true` 跳过退场动画（场景卸载时用）。 |
| `CloseByTag` | `void CloseByTag(string tag, bool immediate = false)` | 按分组标签批量关闭（级联串收尾用）。 |
| `ActiveCount` | `int ActiveCount` | 当前活动对话框数量。 |

**解析优先级**（`Show` 内）：`spec.spawnStrategy`（逐次覆盖）> `RegisterSpawnStrategy(styleKey)`（样式默认）> 静态 `spec.position`。

## 弹出请求：`DialogueBoxSpec`（声明式纯数据）

| 字段 | 类型 | 说明 |
|---|---|---|
| `styleKey` | `string` | 样式键，对应 StyleRegistry 中注册的预制体。 |
| `payload` | `object` | 任意业务数据，由内容视图自行转型。 |
| `spawnStrategy` | `IDialogueBoxSpawnStrategy` | **核心扩展点**。null = 沿用 `position` 静态值 / 样式默认策略。 |
| `position` | `DialogueBoxPosition` | 定位（null = 屏幕底部居中）。与 `spawnStrategy` 并存时以**策略结果**为准。 |
| `layer` | `int` | 层级，越大越靠上；同层按弹出顺序叠放。 |

| `persistent` | `bool` | 点击「继续」是否保留自身（默认 `false` = 点了正常关闭）。由策略或调用方置 `true` 用于级联串保留。仅影响 `StoryLineBoxView` 点击行为。 |

| `tag` | `string` | 分组标签，供 `CloseByTag` 批量关闭。 |
| `onOpened` / `onClosed` | `Action<DialogueBoxHandle>` | 打开完成 / 关闭完成回调。 |
| `Create` | `static DialogueBoxSpec Create(string styleKey, object payload = null)` | 便捷构造（默认底部居中）。 |

## 定位：`DialogueBoxPosition`

> ⚠️ **命名空间变更（2026-08-11）**：`DialogueBoxPosition` 已从 `MicrobialNet.Story.UI` **迁移到 `MicrobialNet.Story`**（运行时数据层），以解除 Runtime→UI 依赖。本文档其余类型仍属 `MicrobialNet.Story.UI`；使用定位结构时（如自定义策略 `Resolve` 内 `new DialogueBoxPosition { … }`）需 `using MicrobialNet.Story;`。

```csharp
namespace MicrobialNet.Story
{
    public struct DialogueBoxPosition
    {
        public DialogueBoxPositionMode mode;  // ScreenAnchor / WorldFollow / Free
        public TextAnchor anchor;             // 屏幕 9 宫格（ScreenAnchor 时生效）
        public Vector2 offset;                // 锚点偏移（像素，y 向上）
        public static DialogueBoxPosition BottomCenter();  // 默认底部居中
        public static DialogueBoxPosition TopRight();     // 新增工厂（右上角）
    }
}
```

## 视图适配器：`StoryView`（TMP 模块）

| 字段 / 方法 | 说明 |
|---|---|
| `spawnMode` | `StoryViewSpawnMode` 枚举（`Config` / `Strategy`）：Inspector 顶部「出现逻辑来源」下拉。二选一——`Config` 用下方三个 position 字段，`Strategy` 用 `defaultSpawnStrategy` 资产。**只显示并只应用选中那一类**；运行时 `Config` 模式不再注入策略，确保二选一生效。 |
| `linePosition` / `choicePosition` / `endPosition` | 三个 `DialogueBoxPosition` 字段（默认底部居中），Inspector 可配；`ScreenAnchor` 全开放，`Free` 交由 Prefab 自身布局。每个字段按 mode 仅显示所需参数（见下）。 |
| `defaultSpawnStrategy` | `DialogueBoxSpawnStrategyAsset` 字段：**仅当 `spawnMode = Strategy` 时生效**。赋值时三类框统一使用该策略决定出现逻辑。⚠️ 全局生效，慎用（见 §12 接线范式）。 |
| `ShowLine(StoryFlow.Line)` | 弹对白框（story-line，layer=10）。 |
| `ShowChoices(IReadOnlyList<StoryFlow.Choice>)` | 弹选项框（story-choice，layer=10，modal）。「带文字」选项（`Choice.Prompt` 非空）先按 `PromptSpeed/PromptTypingMode` 打字机揭示行内对白，**打完后才生成选项按钮**（打字中点击=跳过并立即出按钮）；无 Prompt 的选项直接出按钮、无延迟。选项框位置遵循节点覆盖规则（见 §14——`overridePosition` 且位置非空时用节点位置，否则 `choicePosition`）。 |
| `ShowEnd(bool showText, string text)` | 弹结束 / 提示框（story-end，layer=10）；`showText=false` 时不弹任何框（自然结束）。 |
| （错误不再经 Presenter） | 死路/缺节点/异常结构：仅 `StoryFlow.OnError` 事件 + 控制台 `LogError`，不弹框（story-error 样式已移除）。 |

> 三者均把 `defaultSpawnStrategy` 透传给 `DialogueBoxSpec.spawnStrategy`，因此 Inspector 拖一个资产即可统一接管三类框的出现逻辑。

# 使用与案例

## 内置策略（含 Inspector 可配字段）

> 均带 `[CreateAssetMenu]`：Project 右键 **MicrobialNet / Story / 对话框策略 / …** 创建资产后拖拽配置。

- **`StaticSpawnStrategy`**（静态定位）：把资产上配置的 `position`（缺省回退 `spec.position` 或底部居中）原样返回。等价于"不使用策略"，可作四个 position 字段的复用化替代。
- **`RandomRectSpawnStrategy`**（矩形随机）：在归一化矩形 `rangeNormalized`（x/y/w/h: 0..1，原点左下）内随机取点（分辨率无关）；`avoidOverlap` + `minSpacing` 避让；`maxRetries` 避让重试上限；`historyCap` 已用点记忆上限。跨多次 Show 保持实例，故整段对话可散布且不重叠。
- **`CascadeRandomSpawnStrategy`**（级联随机）：新框围绕"最近弹出的框中心"（`anchorMode = LastCenter`）或"全部活动框几何中心"（`BoundingCenter`）随机半径（`radiusMin`–`radiusMax`）偏移出现；`clampToScreen` + `screenMargin` 夹在屏内；`layerStep` 使层级 = 当前活动数 × 步长（天然最上层）；`closeOnAdvance`（默认 `false`）反向控制 `persistent`（`false` = 保留，级联串默认）。**正是"一串对话保留 + 旧框周围随机 + 最上层"的现成解**。

---

## 自定义策略示例（无需改框架）

```csharp
using UnityEngine;
using MicrobialNet.Story.UI;

[CreateAssetMenu(fileName = "MySpawnStrategy", menuName = "MicrobialNet/Story/对话框策略/我的策略")]
public sealed class MySpawnStrategy : DialogueBoxSpawnStrategyAsset
{
    [SerializeField] private float radius = 120f;
    [SerializeField] private bool keepOpen;   // 级联串保留

    public override DialogueBoxSpawnResolution Resolve(DialogueBoxSpawnContext ctx)
    {
        float ang = Random.value * Mathf.PI * 2f;
        Vector2 anchor = ctx.activeBoxes.Count > 0
            ? ctx.activeBoxes[ctx.activeBoxes.Count - 1].spec.position.offset
            : Vector2.zero;
        Vector2 off = anchor + new Vector2(Mathf.Cos(ang), Mathf.Sin(ang)) * radius;

        return new DialogueBoxSpawnResolution
        {
            position = new DialogueBoxPosition
            {
                mode = DialogueBoxPositionMode.ScreenAnchor,
                anchor = TextAnchor.MiddleCenter,
                offset = off
            },
            layerOverride = ctx.totalActive,   // 永远最上层
            persistent = keepOpen,             // 点击继续是否保留
            delay = 0.1f                        // 轻微错峰
        };
    }
}
```

## 接线范式（注册 / 收尾）

**方式一 · Inspector 全局接管（四类框统一）**
把策略资产拖到场景 `StoryView` 的 `defaultSpawnStrategy` 字段，并将「出现逻辑来源」下拉切到 **生成策略（Strategy）**。⚠️ 该模式下策略对四类框全局生效——`closeOnAdvance=false`（保留）的策略**不要**走这条，否则 choice/end/error 也会持久化、选项选完不关会异常。

**方式二 · 代码按样式注册（推荐用于级联串）**
只对 `story-line` 注册级联随机，避免污染其它样式：
```csharp
// 在某初始化处（如宿主 Configure 后）
var cascade = myCascadeAsset; // 直接持资产引用，或 Resources.Load<DialogueBoxSpawnStrategyAsset>("路径")
DialogueBoxManager.Instance.RegisterSpawnStrategy("story-line", cascade);
```
**收尾（级联串批量关闭）**
```csharp
DialogueBoxManager.Instance.CloseByTag("旁白串");   // 给 spec.tag 设同一分组值后批量关
// 或 DialogueBoxManager.Instance.CloseAll();
```
> 也可给 `spec.autoCloseSeconds` 设值，让保留框到时自动消失，无需手动收尾。

---

## 用户实例对应：一串对话保留 + 旧框周围随机 + 最上层

"CascadeRandomSpawnStrategy"（`closeOnAdvance=false` → `persistent=true`）+ 只对 `story-line` 注册（`RegisterSpawnStrategy("story-line", …)`）。其中"保留显示"由 `persistent` 贯穿 `resolution → spec → handle.Spec → StoryLineBoxView.OnPointerDown` 实现：点「继续」只 `_onAdvance?.Invoke()` 不 `_handle.Close()`；旧框因此逐条保留堆叠。这正是先前"测试会自动关闭"的修补点。**关闭的权责在调用侧**：框架 `Show` 本身不关任何旧框，是否保留取决于 `persistent` 与调用侧是否主动 `Close`。

> 项目侧集成约定（模块定位、依赖方向、Prefab 化、关闭权责边界、验证状态等）见开发记录文档，本文件只提供工具接口手册、不重复项目记录。

# 历史记录

## 节点级外观覆盖（结合剧情节点编辑器，2026-08-11）

把"样式键 / 定位 / 生成策略 / 保留行为"的下沉粒度从 `StoryView` 全局细化到**单个剧情节点**，策划在节点编辑器即可按节点定制对白框表现（无需改 `StoryView` 或剧情代码）。结合粒度 = 节点级（对话节点 `DialogueNodeData` + 选项节点 `ChoiceNodeData`）。

**节点可配字段（反射式 Inspector 面板自动渲染）**
| 字段 | 类型 | 说明 |
|---|---|---|
| `appearanceStyle` | `DialogueBoxStyleAsset` | 样式资产引用（拖拽资产即可）；空 = 用全局默认（`"story-line"` / `"story-choice"`）。节点编辑器内可内联编辑该资产的 `styleKey` / `template` / `introDuration` / `outroDuration`，并可一键「在此节点新建样式资产」。运行时按 `asset.styleKey` 接入样式表（ShowLine/ShowChoices 会即时注册该资产，无需预先全局注册）。 |
| `appearanceOverridePosition` | `bool` | 是否覆盖定位；false = 用 `StoryView` 的 `linePosition` / `choicePosition`。 |
| `appearancePositionMode` / `Anchor` / `Offset` | `DialogueBoxPositionMode` / `TextAnchor` / `Vector2Int` | 扁平定位字段，**仅在 `overridePosition` 真时填写并在 Inspector 显示**（ScreenAnchor→Anchor+Offset）。`Offset` 为整数像素偏移（2026-08-12 由 `Vector2` 改为 `Vector2Int`，节点 Inspector 用 `Vector2IntField` 输入；运行时经 `StoryPlayer.BuildAppearance` 隐式转 `Vector2` 喂给 `DialogueBoxPosition.offset`）。 |
| `appearanceSpawnStrategyKey` | `string`（`[SpawnStrategyPicker]`） | 生成策略键，空 = 用全局默认；**仅当 `appearanceOverridePosition` 未勾选时显示**，避免与定位覆盖同时配置。下拉由编辑器**按类型扫描全部 Assets 目录**渲染资产实例（任意位置可列，不再限约定目录；文件放在约定目录仍推荐——同名 key 解析优先级最高）。 |
| `appearancePersistent` | `DialogueBoxPersistentSetting`（Inherit/Persistent/Transient） | **仅对话节点**；Inherit=跟随全局/策略，Persistent=强制保留，Transient=强制关闭。选项选中即关、不暴露。 |

**透传链路（节点 → 运行时）**
`StoryPlayer.BuildAppearance(d/c)` 组装 `DialogueAppearanceHint`（纯运行期数据，不序列化；字段：`styleKeyOverride` / `overridePosition` / `position` / `spawnStrategyKey` / `persistentOverride(bool?)`）→ 内部 `Line/Choice.appearance` → `StoryFlow.ForwardLine/ForwardChoices` 复制 → `StoryView.ShowLine/ShowChoices` 应用：
```
style     = hint.styleKeyOverride ?? "story-line"
pos       = (overridePosition && position!=null) ? hint.position : (对话用 linePosition / 选项用 choicePosition)
strat     = overridePosition ? null : DialogueBoxManager.Ensure().GetSpawnStrategy(hint.spawnStrategyKey)   // 覆盖位置时忽略策略；否则字符串 key → 资产注册表
persistent = hint.persistentOverride ?? false
```

**优先级规则**：节点覆盖 > 全局（`StoryView` 的 position 字段 / `defaultSpawnStrategy` / persistent 默认 false）。对话与**选项**都按同一规则应用覆盖（`ShowChoices` 的 position 遵循 `appearance.overridePosition`——选项节点自身的覆盖位置长期失效的缺陷已修复；表驱动「表内默认」注入的外观同样走此链路）。

**生成策略按 key 解析（避免 Runtime 反向依赖 UI 资产）**
`DialogueBoxManager` 提供 `GetSpawnStrategy(string key)`：首次调用 `EnsureStrategiesByKey()` **两级注册**——先 `LoadAllAssets<DialogueBoxSpawnStrategyAsset>("")` 扫全部 Resources（业务策略放任意 Resources 子目录即命中；Addressables 定位器空路径返回空、无副作用），再扫约定目录 `Resources/StorySpawnStrategies`（**后注册优先** → 同名 key 以约定目录为准，防业务目录覆盖包约定）；键 = `asset.strategyKey ?? asset.name`。随后按 key 取用。节点字段只存字符串 key，不存资产引用，故 Runtime 程序集不依赖编辑器侧资产引用。

> ⚠️ **策略资产路径约定（易踩坑，2026-09 起放宽）**：**编辑器**侧节点下拉按类型扫描全部 Assets 目录，资产放任意目录都可选；**运行时**解析 = Resources 全扫兜底 + `StorySpawnStrategies` 约定目录同名 key 优先。内置 `Static/RandomRect/CascadeRandom` 是**代码类**不是资产实例——须右键 **MicrobialNet / Story / 对话框策略 / …** 创建资产实例：**放任意 Resources 子目录即可运行时命中**（放约定目录则同名 key 优先级最高）；⚠️ **非 Resources 目录的资产仅编辑器可见、运行时加载不到**（不打包）——正式使用请放 Resources 子目录或经 Addressables 定位器（`IStoryAssetLocator`）。

## 样式资产（DialogueBoxStyleAsset，2026-08-12）

> 此前样式靠**字符串 styleKey** 赋值，易拼错且静默失败。现改为**资产形式**：`DialogueBoxStyleAsset`（ScriptableObject）封装 `styleKey` / `template` / `introDuration` / `outroDuration`，节点与 `StoryView` 都直接拖拽引用，彻底告别手敲 key。

**类型（命名空间 `MicrobialNet.Story`，运行时数据层）**
```csharp
[CreateAssetMenu(fileName = "DialogueBoxStyle", menuName = "MicrobialNet/Story/对话框样式/样式资产")]
public sealed class DialogueBoxStyleAsset : ScriptableObject
{
    public string styleKey;        // 注册键；留空用资产名
    public GameObject template;    // 预制体；留空回退 Resources/StoryDialogueBoxes/{styleKey}.prefab
    public float introDuration = 0.18f;
    public float outroDuration = 0.18f;
    [Range(0, 1)] public float retainRatio = 0.8f;  // 留存过渡占比：下一框等到上一框离场进行到该比例再出现（0=立即出现；1=等完全离场）
}
```
> `DialogueBoxStyle`（样式表数据类）同轮从 `MicrobialNet.Story.UI` 迁至 `MicrobialNet.Story`（与设计 §8 的 `DialogueBoxPosition` 迁移同理，解除 Runtime→UI 反向依赖）。

**创建方式**
- 右键 **MicrobialNet / Story / 对话框样式 / 样式资产** 创建资产实例（建议放 `Assets/.../Resources/StoryDialogueBoxStyles/` 以便运行时自动注册）。
- 或在**节点编辑器**的「对话框外观 · 样式」字段点「在此节点新建样式资产」按钮——节点编辑器即资产组装器，自动建资产并赋值给该节点。

**编辑器内联编辑**：节点「样式」字段渲染为 `ObjectField` + 下方 `Foldout` 展开该资产的 `styleKey` / `template` / `introDuration` / `outroDuration` / `retainRatio`（`[Range(0,1)]` 自动出滑杆），可在节点上直接改样式数据（资产为单一真相源，多节点引用同一资产即共享）。表驱动节点「表内默认 · 统一样式与外观」引用的样式资产同样可内联编辑。

**留存过渡（retainRatio）说明**：连续对白时，若新框在旧框淡出期间立即出现，会盖住旧框造成「瞬移消失」观感。`retainRatio` 让管理器在非立即关闭（`Close()` 而非 `CloseAll(immediate:true)`）时记录旧框离场截止时刻，并把下一次开框延迟到「离场进行到该占比」之后（与策略/调用方自身的 `delay` 取大者）——旧框的淡出过程因此可见。语义边界：`retainRatio = 0` = 不等待（立即出现）；`= 1` = 等旧框完全离场。留存在**样式级**配置：节点引用某个样式资产即自动带上该资产的留存行为，无需在视图或调用方额外传参。

**注册与解析（节点 > 全局）**
- `StoryView` 新增 3 个 `DialogueBoxStyleAsset` 字段（`lineStyleAsset` / `choiceStyleAsset` / `endStyleAsset`）；`EnsureStyles` 注册资产（字段为空则回退内置默认样式 story-line/choice/end）。`ShowXxx` 默认样式键 = `asset?.styleKey ?? 内置 key`。
- 节点引用 `appearanceStyle` 资产时，`StoryPlayer.BuildAppearance` 把 `asset.styleKey` 解析进 `DialogueAppearanceHint.styleKeyOverride`，并把资产引用放进 `hint.styleAsset`；`ShowLine/ShowChoices` 即时 `DialogueBoxManager.RegisterStyle(hint.styleAsset)` 注册该资产，无需预先全局注册。
- 管理器另在 `Show` 时 `EnsureStylesByKey()` 从 `Resources.LoadAll<DialogueBoxStyleAsset>("StoryDialogueBoxStyles")` 兜底注册该路径下全部样式资产。
