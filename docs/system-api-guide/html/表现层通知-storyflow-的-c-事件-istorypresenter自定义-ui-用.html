表现层通知 —— StoryFlow 的 C# 事件 / IStoryPresenter（自定义 UI 用）

底层 StoryPlayer 已 internal，宿主只能经 StoryFlow 这层门面接入表现层。两种驱动自定义 UI 的方式任选其一。

方式 A（推荐）：实现 IStoryPresenter

把"显示对白 / 选项 / 结束"与"收集用户输入"收敛到一个视图组件，经 flow.Configure(presenter) 注入（或同 GameObject 上挂 IStoryPresenter，由 StoryFlow 自动 GetComponent 兜底）。接口方法：

方法 / 事件 签名 说明
呈现对白 void ShowLine(StoryFlow.Line line) 渲染一句对白
呈现选项 void ShowChoices(IReadOnlyList<StoryFlow.Choice> choices) 渲染选项按钮
剧情结束 void ShowEnd(bool showText, string text) 到达 End 节点；showText=false 时不弹任何框（自然结束），text 为可选的结束展示文本
剧情异常 （不再经 Presenter） 死路 / 缺节点 / 异常结构：仅 StoryFlow.OnError 事件对外派发 + 控制台 LogError，不弹框
请求推进 event Action OnAdvanceRequested 视图内点击对白面板时触发 → StoryFlow 转调 Advance()
请求选择 event Action<string> OnChoiceSelected 视图内点击选项按钮时触发 → StoryFlow 转调 Choose(optionId)

TMP 版 StoryView 只是 IStoryPresenter 的一种实现（位于可选模块 com.microbialnet.story.TMP）；宿主可自实现该接口（UGUI / IMGUI / 自绘任意 UI），或传 null 做 headless（测试 / 服务端）。

方式 B：直接订阅 StoryFlow 事件

不实现 IStoryPresenter 时，也可订阅 StoryFlow 的以下 public 事件驱动界面：

事件 签名 触发时机
OnLine Action<StoryFlow.Line> 抛出一句对白（含讲述者、文本、语速、立绘/语音 key）
OnChoices Action<IReadOnlyList<StoryFlow.Choice>> 抛出玩家选项
OnEvent Action<StoryFlow.StoryEventInfo> 事件节点派发（调试/视图用）
OnNodeEnter Action<string> 进入某节点（节点 ID，编辑器高亮/调试）
OnEnd Action 剧情结束
OnChapterChanged Action<string> 章节/图切换（JumpChapter），参数为目标 storyId
OnError Action<string> 死路 / 缺节点 / 异常结构

关键结构体字段

  • StoryFlow.Line：SpeakerId、SpeakerName、Speaker(CharacterViewModel)、Text、Speed、PortraitKey、VoiceKey、appearance(DialogueAppearanceHint)
  • StoryFlow.Choice：OptionId、Text、Prompt、PromptSpeed、PromptTypingMode、appearance(DialogueAppearanceHint)
  • Prompt：选项框顶部说明文字——「带文字」选择节点的行内对白（可空 = 不显示）；自定义 UI 若要复刻框架行为：有 Prompt 时先按打字机揭示（参数 PromptSpeed/PromptTypingMode，与对白节点同语义），文字打完后选项才出现；无 Prompt 直接出选项（选项永不因打字配置而延迟）。点按跳过语义同对白（打字中点击 = 立即全显并出选项）
  • appearance：节点级外观覆盖提示（样式键/覆盖位置/策略键/保留），由视图应用；自定义 UI 可忽略（等价回到全局默认）
  • StoryFlow.StoryEventInfo：Name、PayloadJson

驱动推进的控制方法（在收到 OnLine / OnChoices 后由 UI 调用）：

方法 签名 说明
开始 / 继续 void Play() 装配并开播；已运行则幂等
结束 void Stop() 结束播放
推进对白 void Advance() 收到 OnLine 后，玩家点"继续"时调用
选择选项 void Choose(string optionId) 收到 OnChoices 后，玩家选某项时调用
按序号选择 void Choose(int index) 按最近一次 OnChoices 可见列表下标选
重播 void Restart() 从入口重播、变量归零、清旧进度
状态 bool IsRunning / bool IsWaiting 当前运行 / 等待态，UI 判定按钮态
全局语言 string ActiveLanguage { get; set; } 运行时随时设置显示语言；切章节不回落，详见 §3.1

// 方式 B 示例：订阅事件驱动自绘 UI
flow.OnLine    += line => myUI.ShowDialogue(line.Text, line.SpeakerName, () => flow.Advance());
flow.OnChoices += options => myUI.ShowChoices(options, opt => flow.Choose(opt.OptionId));
flow.OnEnd     += () => myUI.Hide();
flow.Play();
